# RedFlag – The Fraud Files

## Project Overview

RedFlag is a SQL-based fraud detection project developed using MySQL.

The project analyzes transaction data and identifies suspicious transaction patterns using SQL queries.

## Fraud Patterns Detected

1. Velocity Fraud
2. Round-Amount Clustering
3. Card Testing
4. Failed-Then-Succeeded
5. Odd-Hour Concentration
6. Mule Accounts
7. Refund Abuse
8. Merchant Collusion
9. Just-Under-Threshold / Structuring
10. Dormant-Then-Active
11. Velocity Spike
12. Geographic Impossibility

## Technology Used

- MySQL
- SQL
- MySQL Workbench

## Project Files

- `RedFlag_Kshithija.sql` – Contains the SQL queries used to detect the 12 fraud patterns.
- `README.md` – Project documentation.
- `screenshots/` – Contains screenshots of SQL query outputs.

## Dataset

The project uses the provided `redflag_transactions.sql` transaction dataset.

The dataset is not included in this GitHub repository.

## Key Features

- Detects unusual transaction velocity.
- Identifies suspicious round-amount transactions.
- Detects card testing activity.
- Identifies failed transaction patterns.
- Detects unusual transaction timing.
- Identifies possible mule accounts.
- Detects refund abuse.
- Identifies merchant collusion.
- Detects threshold-based transaction structuring.
- Identifies dormant accounts that become active.
- Detects sudden transaction spikes.
- Identifies geographically suspicious transactions.
